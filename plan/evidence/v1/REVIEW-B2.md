## 4. Agreement with the recommendation

**Agree, unchanged from round A2.** AD2 on iOS should take the parent folders of the files CoreText reports through `CTFontCollectionCreateFromAvailableFonts` + `kCTFontURLAttribute` and pass them to `add_source(&DirectorySource { dirs })`. A hard-coded `/System/Library/Fonts` gives the Mac's fonts in the simulator and misses `CorePrivate`; file URLs are ignored by `walk`; the common parent is far too wide. Those folders register 2.5x the files CoreText offers — 133 visible and 92 hidden families beyond UIKit's 86 — which is good for fallback and a display question for FX-3, not a reason to change the folder choice. Chinese still needs a bundled CJK face: iOS draws it with PingFang, whose outlines are `hvgl`, which skrifa 0.44.0 has no reader for, and EffectCraft's fallback then finds nothing that draws Simplified 汉. Round B2 found nothing that shakes any of this.
